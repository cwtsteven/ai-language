Write a program that computes Fibonacci(5) iteratively. Define F(0)=0, F(1)=1, and F(k+2)=F(k)+F(k+1), so the required result is 5. Compute it using a loop rather than returning a hard-coded answer. Allocate integer reference cells i=0, a=0, b=1, and a Boolean reference cell running=true. Maintain the invariant that a contains F(i) and b contains F(i+1). On each iteration, first bind done: Bool to !i == 5. If done, set running := false. Otherwise, bind next: Int64 to !a + !b before changing either cell; then assign a := !b, b := next, and i := !i + 1 in that order. Use while (!running) and return !a after the loop. Use only immutable let bindings and explicit reference cells, := for writes, and ! for reads.
