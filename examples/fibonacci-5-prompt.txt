Write a program that computes Fibonacci(5) iteratively. The sequence starts with zero and one; each later term is the sum of the preceding two. The required result is 5. Compute it using a loop rather than returning a hard-coded answer. Declare mutable integer variables i, a, and b initialized to 0, 0, and 1. Maintain the invariant that a contains the current Fibonacci term and b contains the next term, with i as the current index. Use while (true). On each iteration, first bind let done: Bool = eq(i, 5); then test if (done). If done, execute break; to exit the loop. Otherwise, bind let next: Int64 = add(a, b); before changing either variable; then execute a = b; b = next; let nextIndex: Int64 = add(i, 1); i = nextIndex; in that order. Return a after the loop. Do not allocate a Boolean stop flag: the break; statement exits while (true). Use var for a binding that later statements assign. Assignment is name = atom; and the name reads its current value. let bindings and parameters cannot be assigned. Do not use reference cells, !, assign(), or :=. Use named calls with atomic arguments for all computations; infix expressions are not allowed.
